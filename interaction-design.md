# Interaction Design

Design intuitive, responsive, and emotionally engaging user interactions through purposeful motion, intelligent feedback systems, and polished state transitions that improve usability, clarity, and perceived performance.

Create production-grade interaction systems that feel fluid, accessible, and context-aware across desktop, tablet, and mobile experiences.

## Core Responsibilities

- Design meaningful microinteractions that reinforce user intent and system feedback
- Create smooth page, layout, and shared-element transitions
- Implement polished loading, empty, success, error, and skeleton states
- Build gesture-based interactions optimized for touch and pointer devices
- Add scroll-triggered animations and viewport-aware motion systems
- Design responsive hover, focus, pressed, and active interaction states
- Create drag-and-drop experiences with intelligent visual feedback
- Implement notification, toast, snackbar, and inline feedback systems
- Build optimistic UI patterns for fast-feeling interfaces
- Add contextual animations that guide user attention without distraction
- Design motion systems using spring physics and natural easing
- Create adaptive interactions that respond to user behavior and device capabilities

## Interaction Principles

- Prioritize clarity and usability over decorative animation
- Use motion to communicate hierarchy, relationships, and state changes
- Reduce perceived latency through immediate visual feedback
- Maintain interaction consistency across the entire product
- Design interactions that feel responsive and tactile
- Avoid excessive animation that increases cognitive load
- Ensure transitions are fast, purposeful, and interruptible
- Balance delight with performance and accessibility

## Accessibility Requirements

- Respect `prefers-reduced-motion`
- Preserve keyboard accessibility during animated state changes
- Maintain visible focus states during transitions
- Ensure touch targets remain accessible during motion
- Avoid motion patterns that may trigger vestibular discomfort
- Provide meaningful non-motion feedback when animations are disabled

## Performance Standards

- Prefer GPU-accelerated transforms and opacity animations
- Avoid layout thrashing and expensive repaint operations
- Minimize animation-related re-renders in reactive frameworks
- Optimize interaction performance for low-end devices
- Maintain smooth 60fps interactions whenever possible
- Use lazy-triggered and viewport-aware animations responsibly
