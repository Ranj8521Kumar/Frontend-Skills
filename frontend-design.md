This skill creates visually distinctive, production-grade frontend experiences with strong artistic direction and refined implementation quality.

The goal is NOT just to make interfaces “beautiful.”
The goal is to create interfaces that feel intentionally designed, emotionally memorable, and visually cohesive.

Every interface must feel like it belongs to a clear design world with its own personality, rhythm, typography, motion, and atmosphere.

---

# Core Philosophy

Do NOT generate generic SaaS-style interfaces.

Avoid:
- Generic card grids
- Safe centered layouts
- Default spacing systems
- Bland visual hierarchy
- Overused gradients
- Predictable component structures
- Common AI-generated aesthetics
- Generic “modern UI” styling
- Inter, Roboto, Arial, or default font stacks unless explicitly justified

Instead:
- Build interfaces with a strong visual identity
- Create intentional composition systems
- Use typography expressively
- Design with atmosphere and emotional tone
- Commit fully to one aesthetic direction
- Make interfaces feel authored rather than assembled

The interface should feel like a real designer made it.

---

# Design Thinking Before Coding

Before generating code, internally define:

## 1. Purpose
- What does this interface do?
- Who is using it?
- What emotional response should it create?

Examples:
- Confidence
- Energy
- Calmness
- Mystery
- Precision
- Luxury
- Playfulness
- Technical depth
- Editorial sophistication

---

## 2. Specific Visual Language

Choose ONE strong visual language and commit to it consistently.

Examples:
- Brutalist editorial dashboard
- Retro-futurist spacecraft UI
- Neo-noir developer portfolio
- Luxury fashion magazine aesthetic
- Industrial control panel
- Organic nature-inspired wellness UI
- Art deco booking experience
- Japanese cyberpunk transit system
- Analog scientific instrument interface
- Minimal museum archive system
- Experimental typography-driven portfolio
- CRT hacker terminal aesthetic
- Soft tactile toy-like learning platform

All visual decisions must reinforce this direction.

The interface should feel like it belongs to a recognizable design universe.

---

## 3. Composition Strategy

Intentionally choose a layout philosophy.

Avoid always centering everything.

Possible directions:
- Asymmetrical layouts
- Broken grid systems
- Diagonal flow
- Layered depth composition
- Oversized focal elements
- Dense editorial structure
- Floating panels
- Split-screen storytelling
- Full-screen immersive sections
- Extreme negative space
- Modular architectural layouts

Create visual rhythm and hierarchy through composition.

---

## 4. Typography System

Typography should drive the personality of the interface.

Requirements:
- Use distinctive and expressive font pairings
- Combine a display font with a readable body font
- Create strong hierarchy
- Use intentional letter spacing and line height
- Use scale contrast dramatically when appropriate

Avoid generic typography choices unless intentionally part of the aesthetic.

Typography should feel designed, not default.

---

## 5. Color Philosophy

Build a deliberate color system.

Guidelines:
- Use CSS variables or design tokens
- Favor dominant color relationships over evenly distributed palettes
- Strong restrained palettes are preferred over random colorful UI
- Use accent colors intentionally
- Ensure accessibility and contrast

Examples:
- Monochrome + one harsh accent
- Warm neutrals with muted gold
- Deep charcoal with glowing cyan
- Dusty editorial tones
- Washed analog palettes
- Industrial grayscale with warning orange

Color should reinforce the emotional tone.

---

## 6. Material, Texture & Atmosphere

Interfaces should have environmental depth when appropriate.

Possible elements:
- Grain/noise textures
- Gradient meshes
- Glass surfaces
- Metallic reflections
- Paper textures
- CRT glow
- Soft blur diffusion
- Sharp borders
- Layered shadows
- Decorative framing
- Ambient glows
- Architectural lines
- Pattern systems

Visual details should support the concept, not decorate randomly.

---

## 7. Motion & Interaction Philosophy

Motion should feel intentional and cinematic.

Avoid over-animation.

Focus on:
- One strong entrance animation sequence
- Staggered reveals
- Meaningful hover states
- Smooth state transitions
- Scroll-triggered choreography
- Spatial motion consistency
- Tactile interaction feedback

Animation should reinforce hierarchy and emotion.

Respect reduced-motion accessibility preferences.

# Frontend Engineering Standards

Generated code must be:
- Production-grade
- Fully functional
- Responsive
- Accessible
- Semantic
- Cleanly structured
- Reusable where appropriate
- Visually polished

Use:
- Proper spacing systems
- Component consistency
- Responsive scaling
- Accessible contrast ratios
- Keyboard-friendly interactions
- Sensible architecture

Do not generate fake/demo-looking UI unless intentionally stylized.

---

# Framework & Technology Preferences

When using React:
- Use modern component architecture
- Use Tailwind intelligently, not repetitively
- Use motion libraries meaningfully
- Use shadcn/ui selectively and customize heavily
- Avoid template-like component composition

When using HTML/CSS:
- Prefer elegant CSS systems
- Use CSS variables extensively
- Create layered visual depth
- Use performant animations
- Avoid unnecessary dependencies

---

# Differentiation Requirement

Every generated interface must contain:
- At least ONE visually memorable moment
- At least ONE unexpected composition decision
- At least ONE distinctive stylistic signature

Examples:
- Dramatic oversized typography
- Unusual navigation behavior
- Layered translucent framing
- Experimental grid structure
- Cinematic hero transitions
- Artistic scroll choreography
- Bold asymmetry
- Distinctive hover physics

The user should remember something specific about the interface afterward.

---

# Anti-Generic Rules

NEVER default to:
- Generic startup landing pages
- Basic dashboard templates
- Cookie-cutter hero sections
- Repetitive card layouts
- Safe centered composition
- Random gradient blobs
- Excessive rounded corners everywhere
- Generic “futuristic” blue-purple aesthetics
- Template-like Tailwind patterns

Every design must feel intentional and context-aware.

---

# Final Standard

The interface should feel:
- Designed, not generated
- Cohesive, not assembled
- Memorable, not merely clean
- Intentional, not decorative
- Production-worthy, not conceptual

Think like:
- An art director
- A product designer
- A frontend engineer
- A motion designer
- A typographer

All at the same time.
